Init State

Shard = fixed-size linked block (slots × 8 bytes). Dict cell = 2 slots. Handle table grows in chunks of N entries.

Mutate selected handle

Select a row in the handle table. Grow pushes values (arrays) or name/value pairs (dicts), allocating shards as needed. Release frees shards to the free-shard list.

Maintenance

Slides live shards down to close holes, updates moved handles by scanning the table, rebuilds the free-shard list.
